# Sunrise Drawing Editor

**도면 레이어 선택 및 고품질 추출 전문 프로그램 · v1.6.0**

![Sunrise Drawing Editor](assets/app.svg)

Sunrise Drawing Editor는 환경영향평가, 설계 및 GIS 업무에 사용하는 온맵(OnMap) PDF와 CAD 도면에서 필요한 레이어를 선택하고 보고서에 활용할 이미지를 추출하는 Windows용 프로그램입니다.

## 개발 목적

복잡한 도면에서 필요한 정보만 표시하고 여러 도면을 동일한 조건으로 이미지화하는 반복 작업을 줄이는 것이 목적입니다. 원본 도면을 수정하지 않고 레이어 표시 상태와 출력 조건을 조정할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 도면 관리 | 온맵 PDF, DXF 및 DWG 불러오기와 다중 도면 관리 |
| 레이어 제어 | 레이어 검색, 개별 표시/숨김, 전체 켜기/끄기 |
| 레이어 규칙 | 표시 조건 저장 및 선택 도면 일괄 적용 |
| 미리보기 | 확대·축소·이동, 확대 영역 고해상도 렌더링 및 단계별 진행률 |
| 이미지 추출 | 선택 도면의 PNG·JPG 개별 및 일괄 추출, 완료 후 저장 폴더 자동 열기 |
| 출력 설정 | 원본 자동 해상도 또는 사용자 지정 이미지 크기 및 DPI |
| PNG 출력 조건 | 투명 배경 및 흰 여백 제거 |
| 대용량 처리 | 분할 렌더링, 추출 진행률 및 작업 중단 |
| 작업 환경 | 라이트·다크 테마, 원본 도면 보존 및 출력 파일 덮어쓰기 방지 |

## 지원 환경 및 형식

- Windows 10/11 (64비트)
- 입력: PDF(온맵 등), DXF, DWG
- 출력: PNG, JPG, PDF/SVG(PDF 원본), DXF(DXF 원본의 지원 객체; 보조 출력)
- DWG 사용 시 ODA File Converter 또는 DWG 지원 LibreCAD의 별도 설치가 필요합니다.

## 사용 방법

1. 프로그램을 실행하고 작업할 도면 파일을 추가합니다.
2. 도면 목록에서 원하는 도면을 선택합니다. Ctrl 또는 Shift를 이용해 여러 도면을 선택할 수 있습니다.
3. 레이어 목록에서 필요한 레이어를 켜거나 불필요한 레이어를 끕니다. 반복 사용하는 조건은 규칙으로 저장하고 선택 도면에 적용할 수 있습니다.
4. 미리보기에서 표시 상태와 도면 내용을 확인합니다.
5. 출력 형식(PNG 또는 JPG), 해상도 및 저장 위치를 설정합니다. PNG는 투명 배경과 흰 여백 제거 옵션을 사용할 수 있습니다.
6. **선택 도면 추출**을 눌러 이미지를 저장합니다. 모든 추출이 성공하면 저장 폴더가 자동으로 열립니다.

## 실행 방법

[프로그램 다운로드(Releases)](https://github.com/Peter-msk/Sunrise_Drawing_Editor/releases)에서 공개된 Windows 실행파일을 확인할 수 있습니다. v1.6.0은 통합 소스 후보입니다. 실제 Windows EXE 및 업데이트 검증 후에만 배포합니다.

소스로 실행하려면 [최신 소스 ZIP](https://github.com/Peter-msk/Sunrise_Drawing_Editor/archive/refs/heads/main.zip)을 내려받아 압축을 해제합니다. Python 3.11 이상이 설치된 Windows에서 처음에는 `INSTALL_AND_RUN.cmd`, 이후에는 `RUN.cmd`를 실행합니다.

## 활용 분야

## R08 — 온맵 워터마크 레이어 분리 (개발 소스)

검증된 RGB/SMask 지문을 모두 만족하는 미연결 이미지 XObject만 메모리상 OCG에 연결합니다. 기존 레이어 UI에서 `워터마크 · 국토교통부 국토지리정보원` 체크 해제/복원, 전체 레이어 제어 및 별도 워터마크 그룹 선택을 지원합니다. 기본 켜짐이며, 규칙/그룹 추출은 명시된 선택을 따릅니다. 원본 PDF는 변경하지 않습니다. PDF 출력은 비가시 상태 저장이며 영구 삭제가 아닙니다. 다른 버전의 로고·벡터·문자에는 적용하지 않습니다. 출처표시 및 이용조건을 준수하십시오. 기존 R07 저장 스냅샷은 신규 레이어 키 불일치 시 다시 등록/계획해야 합니다.

신규 회귀 시험: `python -m unittest build.test_v150_ngii_watermark -v`. 합성 PDF의 지문을 테스트에서만 대체합니다. 실제 온맵 및 Windows EXE 검증 전에는 정식 배포/자동 업데이트를 활성화하지 않습니다.

## R09 — 미리보기·출력 스냅샷 경계 안정화 (개발 소스)

등록 원본 식별정보가 없는 호출도 요청 시작 시 원본 식별정보를 확보하고, 전체 레이어 키 및 잠김 상태를 검증합니다. 누락·추가·잘못된 키, 잠김 레이어 변경, 원본 변경 또는 캐시 파서의 원본 버전 불일치 시 요청을 거부합니다. 기존 UI 부분 상태 편집은 유지합니다. R08 워터마크 식별 및 출력 방식은 변경하지 않았습니다. 정식 Windows 빌드·실제 온맵 및 Qt/DPI 검증은 별도 승인 조건입니다.


## R10 — 렌더링 캐시 및 분할 출력 안정화 (개발 소스)

전체 미리보기와 일반 렌더링의 불투명 PNG 캐시 키를 통합하고, 이미지와 페이지 형상 캐시를 함께 해제합니다. 투명 배경 및 확대 영역은 별도 키로 유지합니다. 취소 요청은 캐시 반환 및 분할 렌더링의 DisplayList 생성 전 확인합니다. 분할 렌더링의 선택적 DisplayList 실행 실패 시 해당 타일부터 일반 페이지 렌더링으로 전환하며, 네이티브 픽셀 버퍼를 복사 직후 해제합니다. 기존 출력 옵션·원본 보호·워터마크·빌드 및 배포 정책은 유지합니다. 실제 온맵·대용량 CAD·Windows Qt/DPI 검증은 별도입니다.
