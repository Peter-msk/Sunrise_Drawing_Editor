# Sunrise Drawing Editor — 최종 Windows 실기 Release Gate

현재 시점 이 문서의 Windows 결과는 전부 **NOT RUN**이다. 검증 완료 후 실제 로그와 해시를 기재해야 한다.

## 환경 및 빌드

- Windows 10/11 x64, Python x64 3.11+/3.12, SignTool, 시스템 Python 의존성 확인.
- CMD에서 `set BUILD_RUN_TESTS=1` 후 `BUILD_ONEFILE.cmd` 실행. PowerShell, `.venv` 생성 금지.
- `dist\Sunrise Drawing Editor.exe` 존재·크기·SHA-256, 서명 주체/체인, 빌드 자체진단 전후 로그를 증빙으로 보존. 서명 신뢰는 자체서명/공인 구분.
- 서명 실패나 기동 실패 시 이전 배포 EXE가 보존되는지 확인.

## 실제 402MiB 도면 엔진 검증

- 원본 `3구간 최종 철탑.dxf`(기존 기록상 421,316,933바이트) SHA-256 전·후 동일.
- 기본 표시 → `C0285311` ON → `G0022322` ON → 다중 INSERT ON → OFF 복원.
- 최초 목록화, 선별 적재, DXF 파싱, CAD/PDF 명령 생성, PDF raster, GUI 변경·이미지 저장 단계별 소요시간 측정. 같은 기계·입력·레이어·캐시 조건으로 각 3회 이상 중앙값 및 피크 RSS 기록.
- 반복 확대/이동 25회, 원호 16,692개가 나오는 대표 레이어, INSERT 9,533개 포함 상태, 도면 영역 누락과 좌표·색·축척·순서 검증.
- 기준 ThreePass와 개선본 RGB 해시·결과 PNG SHA-256 비교. 다르면 승인 금지.
- 원본 자동, HD/FHD/QHD/4K, 커스텀 픽셀, DPI, PNG/JPG, 타일 PNG 5500×4567(종횡비 유지) 시험. JPG는 RGB 해시와 재인코딩된 파일 해시를 구분.

## GUI·사용성

- 100% / 125% / 150% / 175% DPI에서 작은 창 및 최대화, 파일 목록·레이어 검색·체크·줌·페이지·추출, 시작/취소/오류 동작 확인.
- QGIS 의존성 없이 독립 PySide6 앱으로 동작하는지, 사용자가 다른 Qt 패키지를 설치한 Windows PC에서도 충돌이 없는지 확인.
- 여러 도면 일괄 상태 적용/추출, 출력명 충돌 시 원본 파일 무변경 및 부분 출력 정리 확인.

## 판정

- 자동시험 PASS + 실물 도면 RGB·원본 해시 PASS + 3회 성능/메모리 측정 + Windows EXE·서명·GUI PASS + 외부 라이선스 검토가 모두 갖춰져야 **배포용 정식본** 승격 가능.
- 한 항목이라도 미실행이면 `NOT RUN`; 합격을 추정하거나 기존 자료로 대체하지 말 것.
