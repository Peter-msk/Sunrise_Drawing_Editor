# Sunrise Drawing Editor — 공식 운영 개발계획서

작성일: 2026-11-12  
기준 상태: 핵심 기능 구현 및 사용자 실기검증 완료 선언 / 공식 소스 승격

## 1. 최종 제품 목표

온맵·DXF·DWG 도면의 레이어를 빠르게 켜고 끄고, 한 번 저장한 레이어 규칙을 다수 도면에 적용해 원본 화질 또는 사용자 지정 해상도로 여러 이미지를 추출하는 **단일 Windows 데스크톱 앱**.

## 2. 설계 원칙

- 작고 단순한 UI, Sunrise 색상·아이콘, 고정 분할창, 라이트/다크 모드
- 입력 도면 원본 보호 및 출력 실패 시 불완전한 파일 정리
- 최초·반복 렌더링의 분리: OCG 레이어 변경, 캐시, PDF clip 및 DisplayList 재사용
- DXF 메타데이터 경량 목록화, 캐시 없는 대형 CAD의 안전한 부분 렌더링
- PNG/JPG 대용량 출력 시 메모리 예산에 맞춰 스트라이프/타일 출력
- DWG는 외부 변환기의 설치 여부에 따라 동작하며 가짜 직접 지원 표시 금지
- Python x64·CMD만 사용하는 Onefile 빌드, 인증서와 소스 분리
- 프로그램 버전 표시·공지·자동 업데이트 없음

## 4. 후속 운영 계획 (필요 시에만 실행)

1. **배포 품질 게이트:** Windows 빌드·SignTool·외부 라이선스·서명 신뢰·샘플 도면 결과를 보관한다.
2. **결함 대응:** 실제 도면에서 누락이 재현되면 객체/레이어 단위로 원인 확인해 최소 수정한다.
3. **성능 대응:** RAM·전체 로딩·레이어 반응·확대 클립·추출 시간을 동일 입력으로 측정한다. 무조건 외부 라이브러리를 늘리지 않는다.
4. **데이터 보안:** GitHub에는 일반 소스만, Drive에는 승인된 ZIP/문서만. 고객 원본·인증서는 올리지 않는다.
5. **아카이브:** GitHub `main`과 Drive 최신 ZIP의 해시를 맞추며 필요 시 이전 공식본은 보존 정책에 따라 관리한다.

## 5. 완료 기준

- GitHub 공개 저장소의 코드가 소스 ZIP과 동일한 기준본임을 검증
- Google Drive의 지정 제품 폴더에서 최신 ZIP 및 문서 3종 조회 가능
- 윈도우 실기 검증 승인 기록과 배포 인증서 상태의 구분 유지
- 공개 소스에 비밀키/내부 로그/실업무 도면이 없는지 확인

**비고:** 사용자 실기검증 완료 선언은 존중하되, 자동시험 및 Windows 서명 상태와 혼동해 새로운 PASS 증거를 만들지 않는다.
