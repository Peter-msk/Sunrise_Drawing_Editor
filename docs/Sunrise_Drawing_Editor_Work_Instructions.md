# Sunrise Drawing Editor — 운영·유지보수 작업지시서

발행일: 2026-11-12  
상태: 공식 소스 승격 후 운영 지시

## A. 배포 전 수행사항

- [ ] `main` 공개 소스의 보안 점검: API 키, 서명 PFX, 개인키, 개인정보, 원본 업무 파일, 사용자 PC 로그/경로 미포함
- [ ] 프로젝트 소스 공개 범위 및 외부 라이브러리 라이선스 이행 검토 (PyMuPDF AGPL/상용, Qt)
- [ ] Windows 10/11 x64에서 `BUILD_ONEFILE.cmd` 실행
- [ ] 가상환경·PowerShell·Qt 다중 바인딩을 생성/실행하지 않는지 확인
- [ ] SignTool 서명 및 SHA-256 검증, Windows 파일 속성에서 발행자 확인
- [ ] 내부 자체서명 사용 시 외부 배포 경고를 숨기지 말 것
- [ ] 실기 검증 승인자의 Windows 시험 로그/환경/날짜를 보관하고 릴리스 증거에 연결

## B. 프로그램 검증

- [ ] 여러 온맵 PDF를 불러와 규칙 저장 → 선택 적용 → 복수 PNG/JPG 출력
- [ ] DXF 100MB 이상과 복잡한 CAD 샘플을 열어 로딩 시간·RAM·객체 누락 검사
- [ ] DWG 변환 엔진이 없는 PC에서는 알기 쉬운 오류 안내; 있는 PC에서는 실제 변환 결과 검사
- [ ] 확대 및 팬 이동 후 이전 레이어 캐시 잔상 없는지 확인
- [ ] 회전/소수점 용지·타일 PNG/JPG 출력 크기·마감 확인
- [ ] 기본 '원본 자동' 해상도와 사용자가 선택한 크기/DPI, 종횡비 보존 확인
- [ ] 라이트/다크 전환 및 고정 패널 화면 마감 확인
- [ ] 원본 파일 SHA-256 변경 없음 확인

## C. 오류 발생 시 최소 수정

1. 문제 파일 형식과 크기, 객체 수, 화면 배율, 레이어 규칙, 출력 모드 기록.
2. 재현 단계와 예외 로그 확보. 개인 경로/업무 데이터는 공개 GitHub에 업로드 금지.
3. 원인 위치 수정 후 영향 있는 자동시험만 우선 수행. 기존 PASS 재검사 불필요 시 생략.
4. 화면·렌더 결과가 달라진 경우 실제 출력 비교 후 교체 ZIP 생성.
5. 실패한 EXE나 서명 안 된 EXE는 공식 배포 위치로 덮어쓰지 않음.

## D. 변경 금지/승인 항목

- 버전 표시, 공지사항, 자동업데이트 기능을 임의 추가하지 말 것.
- 빌드에 PowerShell이나 `.venv`를 다시 도입하지 말 것.
- 원본 자동 해상도를 기본값에서 변경하지 말 것.
- 원본 PDF/DXF/DWG 파일을 침묵 속에 편집·덮어쓰지 말 것.
- 외부 엔진 추가·상용 배포·서명 인증서 교체는 사용자 승인 필요.

## E. 최종 결과물

- 영문·ASCII 이름의 소스 ZIP 1개
- 운영 인수인계서, 작업지시서, 개발계획서 각 1개
- GitHub 공개 소스 커밋과 파일 읽기 검증
- Google Drive 제품 폴더 파일 4개 조회 검증
