# Sunrise Drawing Editor — UI/UX MCP 근거 기반 인터페이스 개선

**상태:** UI/UX 개선 소스 후보. Windows GUI 실기 및 100/125/150/175% DPI 시각검증 전.

## 공개 GitHub 조사 근거

- `redf0x1/ui-ux-pro-mcp` — https://github.com/redf0x1/ui-ux-pro-mcp
  - 공개 README에서 디자인 시스템·타이포그래피·색상·접근성·UX 지침 검색과 구성 도구를 확인.
  - 우리 앱에 반영: `drawing_editor/ui_design.py`의 로컬 테마 토큰, 핵심 CTA 대비, 타이포그래피·상태 안내·키보드 포커스 및 작업 흐름 정비.
- `com55/pyside6-mcp` — https://github.com/com55/pyside6-mcp
  - 공개 README에서 PySide6 위젯 트리·캡처·클릭·키보드·로그·실행검사 기능을 확인.
  - 우리 앱에 반영: Windows QA 시 실제 UI 캡처/geometry를 비교할 수 있는 독립 `quality/qa_gui_layout.py`와 `RUN_UI_QA.cmd` 추가.
  - MCP 서버를 실제 실행하거나 연동한 것은 아님. QA는 기본 Qt만 사용하며 MCP 의존성을 프로그램에 배포하지 않음.

## 실제 적용한 코드 변경

| 대상 | 기존 | 개선 |
|---|---|---|
| 패널 배치 | 파일 248/220px, 레이어 350/320px 고정 | 논리 폭 760/900/1120/1340px 기준 단계형 레이아웃. 각 단계에서 패널 폭 고정, 임의 드래그 없음 |
| 작은 화면·고배율 | 중앙 화면이 세로로 끼일 수 있음 | 작업 영역만 세로 스크롤, 하단 이미지 추출은 항상 화면에 배치 |
| 파일 추가 | 상단 도면 추가 명령 | Windows Explorer 등에서 파일 목록에 로컬 PDF/DXF/DWG 드롭 가능 |
| 빈 미리보기 | 빈 캔버스 | 도면 추가 및 끌어놓기 안내, 실제 렌더링 시작 시 숨김 |
| 레이어 검색 | 일치 결과 0개면 빈 목록 | 검색 결과 없음과 해제 방법을 보조 문구로 표시; 원래 ON/OFF 상태 불변 |
| 일괄 추출 | 선택 도면 추출 | 선택 2개 이상이면 `N개 도면 추출`, 로딩 중에는 비활성화 |
| 접근성 | 아이콘 버튼은 툴팁 중심 | 접근성 이름, 키보드 포커스 순서, 버튼·목록 포커스 링 추가 |
| 테마 | 기존 주황색 CTA와 흰색 글자 대비 3.03:1 | 보수적인 주황색 #B8480B 사용, 흰색 CTA 글자 대비 약 5.29:1 |
| 파일명·상태 표시 | 긴 상태 메시지가 폭을 차지할 수 있음 | 상태 텍스트 자동 생략 및 전체 내용 툴팁 유지 |

## 보존된 계약

- PDF/온맵, DXF, DWG 외부 변환, INSERT/원호 성능 최적화, 레이어 선택 상태, 규칙 저장/적용, PNG/JPG 출력과 원본 자동 기본 해상도 및 고해상도 타일은 수정하지 않음.
- 프로그램 버전 노출, 공지, 자동 업데이트, 새 네트워크/서버 런타임, 필수 MCP 패키지 추가 없음.
- 원본 DXF/PDF 읽기 전용, 이미 PASS한 엔진 기능 보존.
- Windows 운영에서는 `BUILD_ONEFILE.cmd`, CMD, 시스템 Python 사용. 가상환경/PowerShell 자동 생성 없음.

## 검증과 남은 QA

- 전체 Python `unittest` 157/157 PASS (이전 146 + UI 신규 11). Linux/Qt 미설치 환경의 자동시험; **GUI 런타임 검증은 아님**.
- 색상 대비, 논리 폭별 최소 미리보기, 이벤트 연결/접근성/키보드 탭, 검색의 상태 비변경, 전체 소스 문법 검사 PASS.
- 소스코드 비교: UI 파일·신규 토큰/QA/문서/테스트만 변경. CAD 엔진, 빌드 스크립트 및 추출 로직은 변경 없음.
- **NOT RUN**: PySide6 실행 스크린샷, Windows 100/125/150/175% 시스템 DPI 실제 레이아웃, Windows Onefile EXE와 SignTool, 402MiB 실물 DXF.
- Windows QA 경로: CMD에서 `RUN_UI_QA.cmd`로 Qt 캡처 및 geometry JSON 생성. 각 DPI에 대해 실제 화면·잘림·레이어 체크·검색/드롭·추출 팝업 시각 검증을 추가 수행해야 함.
- 사용자 승인 전 GitHub `main` 및 기존 Google Drive 공식 ZIP 변경 금지.
